Images uploaded by hand to the Workshop gallery.

Steam refuses anything over 2MB, so only the upload ready copy is versioned.
PNG masters in this folder are ignored by git.

The gallery is edited on the item page, under Add/edit images & videos. Nothing
in the mod package touches it, and no script generates these: they are real
screenshots of the game.

Images linked from the store description live one folder up and are generated by
tools/Make-Docs.ps1 instead.
