Images uploaded by hand to the Workshop gallery.

The debug action "Shoot every theme" writes straight into LizarbThemes here,
one PNG per theme, as long as the game is running from the working tree. When
the junction points at dist instead, it falls back to the game's own screenshot
folder, so a release build never writes into the repository.

Steam refuses a gallery image over 2MB, so a raw capture has to be converted
before it is uploaded. Only the converted copy is versioned: PNG is ignored
here, everything else is kept.

    ffmpeg -i LizarbThemes/01-Foundry.png -q:v 3 01-Foundry.jpg

NewThemeTemplate.psd is versioned on purpose, and it is large. It is the layered
source of the gallery cards, so a card can be redone later without starting from
nothing. Editor files are stripped from the release package, so it never reaches
a player.

The gallery itself is edited on the item page, under Add/edit images and videos.
Nothing in the mod package touches it.

Images linked from the store description are a different thing: they live one
folder up and are generated by tools/Make-Docs.ps1.
